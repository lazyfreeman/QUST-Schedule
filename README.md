# 青科课程表 (QUST Schedule)

专为青岛科技大学（QUST）打造的课表同步工具。一键将教务课表导入手机系统日历，告别重复输入密码与繁琐菜单，无需后台常驻，省电、准时、省心。

---

## ✨ 核心特色

- **🔐 账号密码本地保存**：仅保存在手机本地，登录态失效时自动代填并登录，免去每次手动输入的麻烦。
- **⚡ 自动寻找与提取课表**：一键全自动登录、进入教务系统并跳转至课表页完成提取，无需手动一步步点击。
- **📅 课表写入系统日历**：直接同步到手机自带日历由系统准时提醒，App 无需后台常驻保活，省电不占内存。
- **☀️/❄️ 夏冬作息自动切换**：自动识别青科大夏冬作息（5月1日~9月30日实行夏令时，下午及晚上推迟30分钟），按具体上课日期精准匹配时间。
- **⏰ 支持自定义作息时间**：内置青科大标准 11 节作息，支持自由修改每节课的起止时间或增删节次。
- **🧠 复杂周次智能识别**：完美支持单双周、跳周、分段周（如 `1-4周,6-12周`）等各类排课情况。
- **🔄 自动覆盖更新与一键清除**：调课或退课后再次同步会自动覆盖旧数据，绝不产生重复日程，也支持一键彻底清空。
- **🌐 校内外网络通用**：通过青科大 WebVPN 直连，无论在校内还是校外家中均可直接更新。
- **🆕 应用内检查更新**：右上角菜单一键检查新版本，支持 GitHub 直连与镜像加速双通道检查与下载，展示更新日志，国内网络也能顺畅获取新版。

---

## 📱 使用步骤

1. **设置学期开学日**：点击右上角设置，确认“开学第一周周一”日期与当前学期校历一致（可选填学号密码以开启全自动更新）。
2. **获取/更新课表**：点击主界面【获取/更新课表】，系统将自动登录并提取全量课程。
3. **一键同步到日历**：点击【同步到系统日历】，授予日历权限后即可完成导入，打开手机自带日历即可查看。

## ❓ 常见问题

- **密码安全吗？**  
  密码仅保存在手机本机，不经由任何第三方服务器，仅用于向学校官方系统发送登录请求。
- **在校外能用吗？**  
  能。App 内置对接青科 WebVPN，校外无需挂任何 VPN 均可正常使用。
- **如何彻底删除导入的课表？**  
  点击 App 内的【从系统日历中移除青科大课表】按钮，即可一键全部清空。
